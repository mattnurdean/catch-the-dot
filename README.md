# Catch the Dot

A fast-paced, lightweight reflex game built entirely with vanilla web technologies. Click the dot as many times as possible within a 30-second countdown.

## Features

- **Zero Dependencies:** Pure HTML5, CSS3, and vanilla JavaScript.
- **Dynamic Positioning:** Dot coordinates adjust dynamically within the game container.
- **Responsive Layout:** Adapts cleanly to mobile and desktop screens.
- **Score & Timer Tracking:** Real-time feedback with automatic end-state handling.

## Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Flexbox, CSS custom positioning)
- **Logic:** Vanilla JavaScript (DOM manipulation, intervals)
